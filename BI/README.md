# Business Intelligence - OLIST

Esta carpeta contiene los componentes del proyecto de Business Intelligence.

## Estructura

- 01_Base_de_Datos: Scripts de creación del DataMart.
- 02_ETL: Procesos de extracción, transformación y carga.
- 03_Power_BI: Reportes y dashboards.
- 04_Pruebas: Validaciones y pruebas de rendimiento.
- 05_Backup_Seguridad: Archivos de respaldo.
