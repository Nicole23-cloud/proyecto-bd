# Business Intelligence - OLIST

Esta carpeta contiene los componentes del proyecto de Business Intelligence desarrollado a partir del conjunto de datos OLIST.

## Estructura

- **01_Base_de_Datos:** Scripts de creación y estructura del DataMart.
- **02_ETL:** Procesos de extracción, transformación y carga de datos.
- **03_PowerBI:** Reportes y dashboards para el análisis de información comercial.
- **04_Pruebas:** Validaciones de calidad de datos, criterios y métricas, y pruebas de rendimiento.
- **05_Seguridad:** Configuración de roles, permisos y mecanismos de seguridad del DataMart.
