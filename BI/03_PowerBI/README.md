# 03. Power BI - OLIST

## 1. Descripción

Esta carpeta contiene el archivo de Power BI utilizado para la visualización, análisis y presentación de los datos del proyecto Business Intelligence basado en el conjunto de datos OLIST.

El reporte permite analizar información comercial mediante indicadores clave de desempeño (KPI), gráficos y visualizaciones interactivas que facilitan la interpretación de los resultados.

## 2. Objetivo

Desarrollar un reporte interactivo en Power BI que permita analizar las ventas de OLIST, identificar tendencias comerciales y proporcionar información relevante para la toma de decisiones.

## 3. Archivo contenido

### `OLIST_ACTUALIZADO.pbix`

Archivo principal del reporte de Power BI del proyecto.

Contiene el modelo de datos, las relaciones entre las tablas y las visualizaciones utilizadas para analizar la información comercial.

## 4. Tecnologías utilizadas

- **Power BI Desktop:** desarrollo del reporte y visualizaciones.
- **SQL Server:** almacenamiento y consulta de los datos del DataMart.
- **DataMart OLIST:** fuente de información para el análisis comercial.

## 5. Análisis y visualizaciones

El reporte permite analizar los indicadores comerciales definidos para el proyecto, como:

- Ingresos totales.
- Artículos vendidos.
- Cantidad de pedidos.
- Comportamiento de las ventas.
- Indicadores de desempeño comercial.

## 6. Resultado esperado

Obtener un reporte interactivo que facilite el análisis de los datos comerciales de OLIST, permitiendo identificar patrones, tendencias y oportunidades de mejora para apoyar la toma de decisiones.
