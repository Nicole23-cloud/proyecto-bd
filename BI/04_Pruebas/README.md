# Pruebas - OLIST

Esta carpeta contiene los scripts y documentos utilizados para realizar pruebas de validación, verificar los criterios y métricas del proyecto, y evaluar el rendimiento del DataMart.

## Contenido
- Pruebas de criterios y métricas.
- Pruebas de rendimiento.
- Validación de resultados.
- Medición de tiempos de respuesta.
