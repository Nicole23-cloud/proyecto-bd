# Evidencia 1 - Dataset OLIST

## 1. Descripción

Esta carpeta contiene los archivos originales del conjunto de datos OLIST, utilizados como fuente de información para el desarrollo del proyecto Business Intelligence.

## 2. Contenido

Se incluyen los Datasets correspondientes a clientes, vendedores, productos, pedidos, pagos, reseñas, ubicaciones geográficas y detalles de pedidos.

## 3. Objetivo

Disponer de los datos originales necesarios para realizar los procesos de extracción, transformación, carga (ETL), modelado dimensional y análisis de información comercial.

## 4. Uso en el proyecto

Los archivos fueron utilizados como fuente de datos para la construcción del DataMart OLIST y el desarrollo de los reportes y dashboards en Power BI.
