# Base de datos Olist

## Descripción
Repositorio que contiene los archivos de datos originales y la versión SQL de la base de datos Olist, utilizados para el desarrollo del proyecto de Business Intelligence y Big Data.

## Contenido del repositorio

### Archivos CSV
- clientes.csv
- pedidos.csv
- detalle_pedidos.csv
- productos.csv
- vendedores.csv
- traduccion_categorias.csv

### Base de datos SQL
- base_datos_general.sql

## Tecnologías utilizadas
- SQL Server
- Databricks
- PySpark
- Power BI

## Objetivo
Almacenar y organizar los datos originales y la estructura SQL de Olist para facilitar su integración, transformación y análisis.
