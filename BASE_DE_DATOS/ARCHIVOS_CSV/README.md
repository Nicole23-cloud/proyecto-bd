# Base de datos Olist

## Descripción
Repositorio que contiene los archivos CSV utilizados para el desarrollo del proyecto de Business Intelligence y Big Data de Olist.

## Contenido del repositorio

- clientes.csv
- pedidos.csv
- detalle_pedidos.csv
- productos.csv
- vendedores.csv
- traduccion_categorias.csv

## Tecnologías utilizadas

- SQL Server
- Databricks
- PySpark
- Power BI

## Objetivo
Almacenar y organizar los datos utilizados en el proceso de integración, transformación y análisis de información.
